# ASCII Zen Garden

A calm little sand garden drawn entirely with text characters. Rake the fallen leaves off the sand, then rake patterns around the rocks, the little maple trees and the pine. Your garden is saved in your browser, so it's still there when you come back.

## Controls

| Action | What it does |
| --- | --- |
| Drag | Use the tool: rake leaves off the edge of the garden, or carve lines in the sand |
| `1` **rake** | Wide, calm parallel lines |
| `2` **fine rake** | Thin little lines for details |
| `3` **smooth** | Flatten the sand back to smooth |
| **fresh leaves** | A gust of wind scatters new leaves |
| **start over** | Smooth sand and new leaves |
| Sound slider (or `M` to mute) | Sand scratching under the rake, rustling leaves, wind chimes and a bamboo water fountain. All the way left is off |

## Run it

Open `index.html` in any browser. No install or build step: it's one self-contained file.
